# 魔法拼音温室 · Pinyin Greenhouse

一款结合 **温室模拟经营** 与 **汉语拼音拼读学习** 的治愈系网页小游戏，拼音数据、助记口诀与标准真人发音资源复用自 [flashtony2005/pinyin](https://github.com/flashtony2005/pinyin)。

## 核心玩法
- **温室栽培花架**：种植声母晶芽与韵母灵花，浇水听读音与顺口溜，成熟收获炼金素材；支持花盆扩建（6 → 12 盆）与多款主题花盆。
- **铜制炼金蒸馏台**：
  - 支持 **两拼音节**、**零声母音节**、**三拼音节**（`声母 + 介母 i/u/ü + 韵母`，如 `j+i+a → jiā`、`d+u+o → duǒ`、`h+u+a → huā`、`j+ü+an → juǎn`）及四声火候调配。
  - 内置 **5 档难度关卡选项**：`自由`、`① 两拼入门`、`② 三拼进阶`、`③ 规则试炼`、`④ 听音大师`（盲听+慢速）。
- **森林村民委托柜台**：看字拼读、规则挑战与听音配药，交付魔药赚取星尘金币并解锁春/夏/秋/冬四季新种子。
- **温室商店与拼音药典**：购买花盆扩建、种子补给包与温室魔法装饰，收录探索全部 424 个标准音节。
