小朋友拼音练习方式：GitHub 开源项目调研

这次不只看「拼音表工具」，而是专门看孩子怎么练：点读、四声、拼合、听辨、闯关、错题复习、听写输出与发音评测。结论用于判断 pinyin-pal 下一步该补什么，而不是推翻现有实现。

范围：GitHub 拼音 / 小学语文学练工具 基准：pinyin-pal 当前四页签 + 五种声调 + 听音辨字 方法：README / 仓库页交叉核对

1先说结论

GitHub 上儿童拼音练习的主流，不是「更大题库」，而是更完整的练法组合。
  • 最基础的共识是：先点读建立音形对应，再做四声跟读和声母+韵母拼合，最后用听音选字检验。
  • 功能最完整的项目会把练习做成「分级关卡 + 即时反馈 + 错题本 + 间隔复习 + 进度可视化」的闭环。
  • 输出型练习（听写、默写、打字）是另一条明显路线，适合从「会认」走向「会写 / 会用」。
  • 发音评测看起来高级，但依赖麦克风、识别准确率和隐私边界；对本项目当前阶段性价比低。
  • pinyin-pal 已经有拼读、五声、例字、规则、顺口溜和听音辨字。真正缺的是练习闭环：分级、错题库、复习调度、家长可见进度。

3六类主流练习方式

每类都给出代表仓库与可借鉴点。功能描述来自各项目 README 或仓库页。

点读 + 呼读音

点击声母、韵母、整体认读卡片即朗读。关键点不是读英文字母名，而是读「呼读音」，例如 b 读成「波」，避免把 b 读成 bee。

代表：candy-learn-pinyin、Pinyin-LeLe、chen2qu/pinyin。
本项目：真人音频已有，继续保持。

四声跟读 + 手势

同一拼音配四个声调按钮，部分项目配「平、扬、拐、降」手势图，帮助孩子用动作记忆调型。

代表：Pinyin-LeLe、mlp-pinyin「声调彩虹」。
本项目：五声按钮 + 调号已有，手势图可作为后续增强。

拼读拼合

选声母、韵母、声调合成音节。进阶项目会区分两拼与三拼，并解释 j/q/x/y 与 ü 的书写规则、ian/uan/üan 的变音。

代表：chen2qu/pinyin、learnPinyin、mlp-pinyin「拼读城堡」。
本项目：拼读 + ü 规则 + 标调规则 + 顺口溜已有。

听音辨字 / 听音选字

播放发音，从候选中选正确字母、音节或例字。检验「听到音 → 找到字形/字义」的映射，是儿童拼音 App 最常见的练习。

代表：candy-learn-pinyin、mlp-pinyin、拼音岛。
本项目：已有 4 选 1 听音辨字，但题型单一、无错题沉淀。

分级闯关 + 错题库 + 复习

按教材或难度拆关卡，答题后即时反馈，错题自动记录，再用遗忘曲线或间隔算法安排复习，配合积分/成就维持动机。

代表：PinyinAdventure（人教版分级、汉字/词语/句子、艾宾浩斯、错题本）、xiaoxue-typing 1.6.0（SM-2 学习步、每日上限、7 天热力图）。
本项目：只有即时对错与计分。

输出型练习

听写、默写、跟读、闪卡、落字等，把「认拼音」推进到「写出 / 打出拼音」。也有项目直接生成可打印的看拼音写词练习纸。

代表：xiaoxue-typing 七种玩法、deepin-pinyin-assistant、pinyin_practice。
本项目：暂无，移动端打字对低龄孩子成本偏高。

5pinyin-pal 下一步：优先级建议

建议保持现有浅色、一屏、离线的产品性格，只补「练」的闭环。

P0 · 把听辨做厚

成本最低，直接复用现有音频和例字库。
  • 题型扩展听音选拼音、听音选例字、看拼音选例字、听音选声母/韵母、四声辨析。
  • 错题库答错自动进入错题集，下一轮优先重练；至少先在本次会话内生效。
  • 干扰项策略从同声母、同韵母或形近/音近项里取，避免全是随机汉字。
  • 结果反馈答对显示音节 + 例字 + 一声调提示；答错显示正确答案并立即再听一次。

P1 · 关卡化与复习

从「随手练」变成「按路径练」。
  • 五关地图声母森林 / 韵母海洋 / 整体认读 / 声调彩虹 / 拼读城堡，映射 mlp-pinyin 结构。
  • 轻量间隔复习先做简化 SM-2：会了→延后；不会→10 分钟后/下一轮再出现。
  • 每日上限每日新题 10、复习 20，避免孩子一次练太久。
  • 进度页连练天数、正确率、7 天热力图；全部本地存储，不引后端。

P2 · 增强但别急着做

有价值，但不符合当前阶段的主线。
  • 声调手势图四声配平/扬/拐/降手势，适合认知增强。
  • 家长报告周报、薄弱声母/韵母清单、可打印练习纸。
  • 口语评测需要麦克风权限和可靠识别，先只做概念储备。
  • 大屏投屏沿用 pinyin-vue 的家庭场景，等平板端稳定后再做。
不建议照搬：PinyinAdventure 的 Supabase 后端、Pinyin-LeLe 的 Gemini API、mlp-pinyin 的 Azure TTS，都与「完全离线、单实例、无密钥」定位冲突。可以借的是算法、题型和数据组织，不是依赖。

6可直接吸收的细节清单

发音与规则

呼读音b 读「波」而不是英文字母名；本项目真人音频已覆盖，规则文案可继续强调。
短音拼读点韵母时发音别拖太长，更接近真实拼读节奏（chen2qu 1.8.1）。
变音说明ian / uan / üan、y + u/ü 的书写与读音差异，可继续补进知识页。
轻声目前回退第一声；若要补真实轻声，需要新音频素材，不是算法问题。

交互与界面

柔和配色本项目已用浅蓝声母 / 浅绿韵母；继续避免高饱和糖果色堆叠。
单层字形拼音优先选 a/g 单层字形字体，贴合小学规范。
即时奖励答对可以轻庆祝，但不必全屏彩带；保持学习氛围安静。
iOS 音频解锁若未来做 iOS，参考 candy-learn-pinyin 的首次交互解锁机制。
